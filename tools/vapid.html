알림용 키 만들기

아래 버튼을 누르면 이 기기 안에서 키 한 쌍이 만들어집니다. 만든 키는 어디에도 전송되거나 저장되지 않으며, 이 화면을 닫으면 사라집니다.

1. Public Key (공개해도 되는 키)

복사됨

이 키는 채팅에 붙여 주세요.

2. Private Key (비밀 키)

복사됨

이 키는 채팅이나 다른 곳에 붙이지 말고 Supabase 의 Edge Functions → Secrets 에만 넣어 주세요. Supabase 에 넣을 때까지 이 화면을 닫지 마세요. 닫았다면 키를 새로 만들어 두 키를 모두 다시 쓰면 됩니다.
